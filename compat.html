八年级第9课 · 六个互动任务

  1. 数据接力：分清哪些数据来自互联网，哪些由传感器或卫星自采。
  2. API 取数：选天气接口和北京，发送请求，从返回 JSON 中取出温度、湿度、风力。
  3. HTTP 快线：组好 GET 请求，观察“请求 → 服务器处理 → 返回响应”。
  4. 负载实验：让 500 台设备每 1 秒轮询，观察请求量、服务器负载和设备能耗。
  5. 协议匹配：把低功耗、低带宽、低延时、兼容性匹配到真实场景。
  6. 协议决策：为电池供电、网络较弱的校园智慧农场选择合适协议。
怎样打开完整互动版：在 Windows 7 上安装 Chrome / Edge 109（或使用手机、新电脑），双击压缩包里的“打开课堂网站.bat”，或直接打开 index.html。完整版支持每站“↻ 重做”和整节课“重做第9课”。
